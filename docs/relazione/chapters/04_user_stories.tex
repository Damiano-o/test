\chapter{User Stories}\label{ch:stories}

Each user story follows the mandatory format
\emph{``As a \textless role\textgreater, I want to
\textless capability\textgreater, So that \textless benefit\textgreater''}
and satisfies the INVEST criteria (Independent, Negotiable, Valuable,
Estimable, Small, Testable). The login is not modelled as a story: per the
course rule, authentication is a precondition of the primary use cases and
is realised by UC-11 through the \emph{include} relationships.
